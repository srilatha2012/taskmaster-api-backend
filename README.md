# TaskMaster API Backend

## 1. Project Overview
TaskMaster API is a secure RESTful API for managing users, projects, and tasks.
User's can register, log in, create projects and manage tasks inside their own projects.
Authentication and Authorization ensure users can access only their own data.

## 2. Project Goals
 - Build a RestFul API's with Express
 - Design Mongo DB models with mongoose
 - Implement JWT Authentication
 - Protect routes with middleware
 - Apply ownership-based authorization
 - Practice clean folder structure
